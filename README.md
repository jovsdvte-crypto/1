# 日常メモ・日記

日常の思い付き・メモ・日記・買い物リストを記録するリポジトリです。

## ファイル構成

- `買い物リスト.md` … 買うものリスト（買ったらチェック）
- `やることリスト.md` … やることリスト（終わったらチェック）
- `ふるさと納税.md` … ふるさと納税の予算・寄付済み・候補メモ
- `森実さんに頼むことリスト.md` … 森実さんに頼む・相談すること
- `日記/` … 日付ごとの日記・メモ（`YYYY-MM-DD.md`）

## 使い方

思い付いたことを送ってもらえれば、内容に応じて適切な場所に記録します。
- 「買うもの」→ 買い物リストへ
- 日々の出来事・考えごと → その日の日記へ
